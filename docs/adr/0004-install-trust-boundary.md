# 安装动作的信任边界：v1 不做确认弹窗，写入即信任

`/skill install` 的语义是「把一段 Markdown 指令注入本会话之后所有模型对话」，等价于执行来自外部的提示词。v1 决定：命令面板中安装动作直接执行、不设二次确认弹窗——因为该命令由用户在命令平面显式输入、结果不入模型历史，信任边界与 `/plan`、MCP 服务器挂载等既有 profile 操作一致；并在文档与命令输出中明示「所装技能将立即进入模型目录」。

## Status

accepted

## Consequences

- 若未来支持从模型侧发起安装（如模型调用安装工具），必须引入确认机制；该能力列入 P2 候选。
- 校验镜像规则（拒绝驼峰键/非法名/非布尔值）是对该信任边界的补强：至少保证注入内容格式合法、可被发现。
